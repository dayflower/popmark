# Commit Message Convention

All commit message titles must start with a conventional commits type prefix:
`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`, `style:`, `perf:`, `ci:`, `build:`

- Title line only — no body lines beyond the Co-Authored-By trailer
- Written in English
