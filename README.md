# Popmark

A quick-access Markdown scratch pad that lives in your menu bar.

Press a global hotkey to bring up the editor, write your Markdown, and send it to the clipboard — then get on with whatever you were doing.

## Features

- **Source-visible WYSIWYG editor** — Markdown syntax stays visible while styling is applied live (Obsidian-style)
- **Send to Clipboard** — copies your content as plain Markdown and hides the window in one keystroke
- **Auto-save draft** — your work is never lost; the editor restores exactly where you left off
- **History** — every document you send to the clipboard is saved and accessible from the side panel
- **Export** — save the current document as a `.md` file at any time
- **Global hotkey** — show or hide the editor from anywhere without switching apps
- **Launch at login** — always ready in the background

## Supported Markdown

Headings (H1–H6), **bold**, _italic_, ~~strikethrough~~, `inline code`, fenced code blocks, blockquotes, unordered and ordered lists, task lists (`- [ ]` / `- [x]`), horizontal rules, and links.

## How to Use

1. Press the global hotkey (default: **⌥M**) — the editor appears.
2. Write your Markdown content.
3. Press **⌘↩** (or click the Send to Clipboard button) — content is copied to the clipboard and the window hides.
4. Paste wherever you need it.

The editor window can also be opened from the tray icon or the Dock icon.

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| ⌥M (default) | Show / hide the editor window |
| ⌘↩ | Send to Clipboard and hide |
| ⌘N | New document (saves current draft to history) |
| ⌘S | Export current document as a `.md` file |
| Esc | Hide the editor window |

> The global hotkey can be changed in Settings. On Windows and Linux, the default shortcut may differ.

## Settings

Open Settings from the tray icon menu or the app menu.

| Setting | Description |
|---------|-------------|
| Global hotkey | Key combination to show / hide the editor window |
| Launch at login | Start Popmark automatically when you log in |
